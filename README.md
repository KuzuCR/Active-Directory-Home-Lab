# Active-Directory-Home-Lab
Active Directory Home Lab

This repository provides scripts and instructions for setting up a home lab environment with Active Directory (AD) using PowerShell. It covers essential AD management tasks, from initial domain setup to creating user accounts, organizational units (OUs), and applying group policies for a structured, secure environment.

Contents

1. Domain Setup
Steps to configure a new domain controller in a Windows Server environment.
Instructions for promoting the server to a domain controller using PowerShell.
2. User and Group Management
Scripts to automate the creation and organization of user accounts and security groups.
Procedures for assigning users to groups based on roles and permissions.
3. Organizational Units (OUs)
Guide for creating OUs to logically organize resources.
Instructions for applying policies and managing permissions at the OU level.
4. Group Policy Objects (GPOs)
Configuration scripts for setting up GPOs that enforce security and operational standards.
Methods for automating GPO application to user and computer OUs.
5. Permissions and Access Control
Procedures for managing access permissions across resources.
Applying role-based access controls (RBAC) to maintain security and resource management.
Key Skills Developed

Active Directory Fundamentals: Understanding the basics of AD setup and structure within a lab environment.
PowerShell Automation: Using PowerShell to streamline AD tasks, such as user management and permissions.
Group Policy Management: Configuring and applying GPOs to enhance security and consistency.
Organizational Structure: Building a logical structure of OUs to segment resources efficiently.
Tools and Technologies

Windows Server: Utilized for AD and domain controller configurations.
PowerShell: Primary tool for automating AD setup, management, and policy applications.
